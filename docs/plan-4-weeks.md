# Kế hoạch 4 tuần

## Tuần 1 — Nền tảng

Chốt luật, Git flow, UML và kiến trúc. Kiệt làm Board/Ship/Fleet và test đặt tàu; Sỹ làm state/lượt; Nam tạo WPF shell; Phát chuẩn bị thiết kế UI/âm thanh. Cuối tuần merge Domain và cửa sổ game khung.

## Tuần 2 — Gameplay và AI

Hoàn thiện đặt tàu thủ công, bắn, đổi lượt, thắng/thua và timer 30 giây. Kiệt triển khai Easy, Medium, Hard; Sỹ tích hợp GameSession; Nam nối hai lưới; Phát làm thông báo tàu chìm. Cuối tuần phải chơi được một ván từ đầu đến cuối.

## Tuần 3 — SQL và trải nghiệm

Tạo database, Users/Games/Shots, đăng nhập và lưu kết quả. Làm leaderboard, lịch sử phát bắn, nút chơi lại, hiệu ứng/âm thanh. Mỗi tính năng đi qua pull request và được một thành viên review.

## Tuần 4 — QA và bàn giao

Test biên, bắn trùng, timeout, tất cả bot và SQL. Cân bằng độ khó, sửa lỗi, hoàn thiện UML/README/proposal, build release và tập demo.

## Definition of Done

Code build được, luật có test, UI không tự thay đổi state game, dữ liệu lưu đúng, có hướng dẫn chạy và thành viên khác đã review.
